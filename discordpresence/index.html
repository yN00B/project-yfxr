Running it

1

Install the one dependency — open a terminal and run pip install pypresence. That's the whole install.

2

Make sure Discord is open on the same machine. The script talks to it over a local socket — nothing leaves your computer.

3

Run the file — python launcher.py. Your status appears within a couple seconds and stays live until you close the script.

4

Edit anytime — change values up top and rerun, or come back here and download a fresh version.
